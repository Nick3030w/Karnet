## 📌 Descripción

**Karnet** es una aplicación móvil desarrollada con Ionic que permite a los estudiantes de la Fundación Universitaria Konrad Lorenz validar su identidad de manera digital dentro de la institución.

La aplicación genera un **código QR dinámico**, el cual puede ser utilizado para procesos como:

- 📚 Préstamo de material en biblioteca  
- 🎲 Acceso a material lúdico institucional  
- 🏫 Validación rápida de identidad  

El objetivo es reemplazar o complementar el carnet físico, optimizando tiempos y mejorando la experiencia de acceso a servicios internos.

---

## 🚀 Características principales

- 🔐 Inicio de sesión con correo institucional  
- 🪪 Visualización de identidad del estudiante  
- 📷 Generación de código QR funcional  
- ⚡ Interfaz rápida y responsiva  
- 📱 Experiencia optimizada para dispositivos móviles
